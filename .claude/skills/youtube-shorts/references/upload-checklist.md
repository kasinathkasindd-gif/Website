# Upload and cross-post checklist

## YouTube Short
- [ ] **File:** 1080×1920, H.264, ≤ 60 s for this series (Shorts can run to 3 min), loudness about −14 LUFS.
- [ ] **Title (≤ 60 characters):** district + "India" (or the state) + a hook.
  - Rotate formulas: fact-first / day-of-eating / question / counter.
- [ ] **Description:**
  - Line 1: hook + "District N of TOTAL".
  - Line 2: what Seetu ate (3 dishes).
  - Then: "Sources:" with 2–4 key sources, a link to the open data table, the correction policy ("Locals, correct us — we check every comment against sources"), and translated titles/descriptions.
- [ ] **Hashtags (3–5):** #WhatIndiaEats + #<State> + #IndianFood (+ district / #DayOfEating).
- [ ] **Thumbnail / cover:** a custom Shorts thumbnail if the channel has the feature (YPP rollout, July 2026); otherwise pick a frame. Seetu's emotion + hero dish + ≤3 words.
- [ ] **Playlist:** state season + themed playlists.
- [ ] **Related video:** the state long-form or playlist.
- [ ] **Disclosure:**
  - Animated → no AI label needed.
  - Any photorealistic AI footage → tick *altered or synthetic content*.
  - Paid promotion → tick *paid promotion*.
- [ ] **Language:** set the video language to English. Enable auto-dubbing if eligible, and check the dubbed dish names.
- [ ] **Pinned comment:** one question. Reply to comments for the first 30 minutes.
- [ ] **Time:** Slot A 14:30 UTC (Slot B 23:00 UTC when posting twice a day). Switch to the audience-activity report after 30 days.

## Instagram Reels (+2 h)
- [ ] Native upload of the same master; no watermarks.
- [ ] Caption: 2-line hook + 3–5 hashtags + "Save this for later".
- [ ] Carousel of 3 recipe-diary cards (same data, different post) to drive saves.
- [ ] Use Trial Reels to test hooks with non-followers.
- [ ] Music must be from the original library (YouTube Audio Library standard tracks are not allowed here).

## Facebook Reels (+4 h)
- [ ] Native upload; longer story caption, question first.
- [ ] Check eligibility in the Professional Dashboard for Content Monetization.
- [ ] Share only in groups whose rules allow it.

## Learn (48 h and 7 days after publishing)
- [ ] Retention curve: where do viewers drop? Tag the beat (hook / breakfast / …).
- [ ] Swiped-away rate vs channel median → rotate hook types if it's high.
- [ ] Top geographies → adjust titles, translations and posting slot.
- [ ] Comments → corrections queue → verify → update the table and log the change.
  - If a correction changes a published fact, pin a correction comment.
- [ ] Log credits spent vs quoted.
