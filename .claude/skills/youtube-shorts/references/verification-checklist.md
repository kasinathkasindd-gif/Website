# Verification checklist (Phase 1 rules, operational)

## A. District list (per state, before research)
- [ ] Pull the official LGD (lgdirectory.gov.in) district export for the state. Save the file and the date.
- [ ] Search for creations, mergers and renames since the export date: gazette notification, cabinet decision, effective date.
  - Record all three dates. Announcements ≠ notifications.
- [ ] Note census or administrative freezes (e.g. Census 2027 freeze: 1 Jan 2026 – 31 Mar 2027).
- [ ] Decide the special cases and record them:
  - census-only districts with a distinct culture (e.g. Mahé, Yanam) → separate episode
  - capital complexes counted as districts (e.g. Itanagar Capital Complex)
- [ ] Set the route order inside the state: a snake through adjacent districts. Check adjacency on the official map.

## B. Each row (district × meal)
- [ ] Everyday home food only. No restaurant, festival or guest-only food (those go in Unique fact, labelled).
- [ ] Local name in native script + romanisation + English meaning.
  - **Native script must come from a source or reviewer. Never guess it.**
- [ ] Ingredients list (main ones).
- [ ] Method: key steps, vessel, approximate time.
- [ ] At least 2 sources from **different publishers**, tier A–C:
  - A: official (government, UN, Guinness, GI registry, ICAR, census)
  - B: academic
  - C: regional press, food writers, cultural encyclopaedias
  - D (recipe/cookbook) only supports ingredients and method.
  - E (Wikipedia, travel operators, hotel/SEO/AI pages) is a pointer only and **never counts**.
- [ ] Status:
  - **Verified:** ≥2 independent A–C sources tie the dish to *this district or a named sub-region containing it*, and the details agree.
  - **Partially verified:** ≥2 sources at state or sub-region level but none for this district; or only 1 district-specific source.
  - **Unverified:** 1 source or inference.
- [ ] Data basis, one of:
  - `District-specific`
  - `Sub-regional: <name>`
  - `State pattern (no district-specific data found)`
- [ ] Community check:
  - If the district's communities eat differently, show both and mark the row Partially verified.
  - Never present a minority community's dish as the whole district's.

## C. Unique fact
- [ ] Separate status from the dish row.
- [ ] Numbers: copy the source's phrasing ("up to", "about"). Where sources differ, give the range and say "sources vary".
- [ ] Dates: distinguish announced vs notified vs effective.
- [ ] Attribution: contested claims are attributed ("researchers found…", "a traditional account says…").

## D. Contradiction pass (a second, separate read)
- [ ] For every number, date and count: does any source disagree? If yes, write it in Notes. Don't silently pick one.
- [ ] Check that a "first / only / largest" claim is supported by the strongest source, not by a blog.

## E. Sensitivity pass
- [ ] No value words about food (weird, gross, exotic, poor man's).
- [ ] Beef, pork and vegetarian food are described factually.
- [ ] No religious, caste or political symbols as jokes.
- [ ] No stereotyped tropes not supported by the data (e.g. the "dog meat" trope for the Northeast).
- [ ] Prices: dated source, local currency first, approximate US$ with the conversion date.

## F. Local review (lifts 🟡 → ✅)
- [ ] One reviewer per state (food writer or home cook from the district).
- [ ] The reviewer confirms dishes, native-script names and pronunciations.
- [ ] Corrections are logged with a source, or as "local testimony (name, date)".
- [ ] Viewer comments are **leads**, not sources: verify before changing the table.

## QA (before publishing each episode)
- [ ] Every VO sentence and on-screen fact maps to a row ID in the script's fact-check table.
- [ ] Statuses still hold (re-check if the table changed after the script was written).
- [ ] Partially verified facts are phrased regionally; no Unverified claim appears.
- [ ] Dish visuals checked against reference photos (shape, colour, vessel). Fix or regenerate if wrong.
- [ ] Captions match the VO word for word; names are spelled as in the table.
- [ ] Description lists the 2–4 key sources and links the data table.
